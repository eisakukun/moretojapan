## 独自ドメインにしたくなったら

いまのURLは無料でSSLも付いている。人が来るようになってから買えばいい。
年1,500〜2,000円が `.com` の相場（お名前.com、ムームードメイン、Cloudflare Registrar など）。

買ったあとにやること：

1. リポジトリに `CNAME` というファイルを作り、中身に買ったドメインだけを1行書く
2. ドメイン屋のDNS設定で、`A` レコードを4つ足す
   `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`
   （`www` を使うなら、かわりに `CNAME` を `eisakukun.github.io` に向ける）
3. GitHub のリポジトリ設定 → Pages → Custom domain に入力して Enforce HTTPS を入れる

反映に数時間かかることがある。1〜3はやり方を言ってくれれば全部こちらで書く
（買う操作＝カード入力だけは本人がやる必要がある）。

## カタカナ・キャッチ

- **もじモード** … ローマ字（NA）が出る。同じ音のカタカナを取る。答えのカタカナは伏せてある
- **ことばモード** … 外来語（コーヒー、コンビニ、パスポート…）が出る。左から順に取る
- おとりの半分は **わざと見た目がまぎらわしい字**（シ/ツ、ソ/ン、ク/ケ、ナ/メ…）から出る
- 取ると音が鳴り、その字・その言葉を読み上げる
- 間違えて取ると「✕ ツ = tsu」と、何を取ってしまったのかが出る（ここが一番おぼえる）
- 終わると「取れたことば」の一覧が出て、体験レッスンへのリンクが出る

当たり判定は手だけでなく **頭・ひじ・腰・ひざ・足** にもある。大きさは肩幅から決めるので、
部屋のどこに立っていても同じ感覚で取れる。

### カメラなしで中身を確認したいとき

```
http://localhost:8021/katakana-catch.html?mouse=1
```

`?mouse=1` を付けるとマウスの先も「手」として当たる。ふだんの遊びには出てこない。
