# 日本語を教えるホームページ（nihongo-site）

日本語を勉強したい人・日本に住んでいる人に向けたレッスンの入口ページと、
集客用の無料ゲーム「カタカナ・キャッチ」。

- `index.html` … トップページ（英語表示、右上のボタンで日本語に切り替わる）
- `katakana-catch.html` … 体でカタカナを取るゲーム（MediaPipe の姿勢認識）
- `vendor/` … MediaPipe 本体・wasm・姿勢モデル（約24MB）。**ネットが無くても動くための焼き込み**

## 見る

```bash
python3 -m http.server 8021 --directory ~/nihongo-site
```

そのあと http://localhost:8021 を開く。
`file://` で開くとカメラが動かないので、必ずこの方法で開くこと。

## 公開する前に書き換えるところ（3か所だけ）

| 場所 | 何を | 目印 |
|---|---|---|
| `index.html` の一番下の `<script>` | 自分のメールアドレス | `CONTACT_EMAIL = "your-address@example.com"` |
| `index.html` の Price セクション | 料金（いまは ¥0 / ¥3,000 / ¥13,500 の仮の数字） | `★ここを自分の金額に書き換える` |
| `index.html` の About セクション | 自己紹介 | `★自己紹介を自分の言葉に` |

申し込みフォームはサーバーを使わない。書いた内容をそのままメール本文にして、
相手のメールアプリを開く方式。無料で、どこにもデータを預けない。

## カタカナ・キャッチ

- **もじモード** … ローマ字（NA）が出る。同じ音のカタカナを取る。答えのカタカナは伏せてある
- **ことばモード** … 外来語（コーヒー、コンビニ、パスポート…）が出る。左から順に取る
- おとりの半分は **わざと見た目がまぎらわしい字**（シ/ツ、ソ/ン、ク/ケ、ナ/メ…）から出る
- 取ると音が鳴り、その字・その言葉を読み上げる
- 間違えて取ると「✕ ツ = tsu」と、何を取ってしまったのかが出る（ここが一番おぼえる）
- 終わると「取れたことば」の一覧が出て、体験レッスンへのリンクが出る

当たり判定は手だけでなく **頭・ひじ・腰・ひざ・足** にもある。大きさは肩幅から決めるので、
部屋のどこに立っていても同じ感覚で取れる。

### カメラなしで中身を確認したいとき

```
http://localhost:8021/katakana-catch.html?mouse=1
```

`?mouse=1` を付けるとマウスの先も「手」として当たる。ふだんの遊びには出てこない。
